# R10 Field Guide

An interactive guide to the Canon EOS R10 (firmware 1.7.0) with the RF-S18-150mm lens. It has a clickable 3D body, the full menu tree, the shooting screen and the 1.7.0 changes.

Open `static-assets/tools/canon-eos-r10-field-guide/index.html` in a browser (published at https://jermolene.com/tools/canon-eos-r10-field-guide/); there's nothing to build. three.js r128 and Google Fonts load from CDNs.

- `CLAUDE.md`: rules for working on it
- `HANDOVER.md`: architecture, sources, known gaps, next steps
- `tools/screenshot.sh`: headless render check

Not affiliated with Canon. Menu structure is from Canon's EOS R10 Advanced User Guide.
